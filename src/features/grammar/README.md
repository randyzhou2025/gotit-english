# 独立语法模块（第一版）

入口是首页快捷操作中的“语法课堂”，与导出词表、单词消消乐同一行，图标为“语”。底部保留首页、同学、生词本、我的四项；首页在内容超出一屏时自然滚动。教材选择、词库、听写、消消乐、生词本及单词掌握记录没有接入或改写。语法目录、讲解、练习、结果均使用微信原生页面栈；从首页进入目录可以原生返回，练习结束返回已有目录，不重复叠加目录页。

## 内容与来源

- `content.generated.json`：从 `doc/英语时态` 的四份最新 DOCX 正文及答案成对导入。DOCX 与同名 PDF 配套，读取段落和表格，保留原版措辞。
- 核心10课，每课16道课后练习及25项专项训练；另有44道跨时态题、12处综合语篇填空、10项写作。共476项，全部有答案与解析，语篇题保留完整上下文。
- `extensions.ts`：依据包内《英语16种时态总览_无课标口径.svg》补充另外6种，讲解和30道练习明确标为拓展补充。
- 拓展讲解校核参考：Cambridge English Grammar Today 的 [would](https://dictionary.cambridge.org/grammar/british-grammar/would)、[past perfect continuous](https://dictionary.cambridge.org/uk/grammar/british-grammar/past-perfect-continuous-i-had-been-doing)、[future perfect continuous](https://dictionary.cambridge.org/grammar/british-grammar/future-perfect-continuous-i-will-have-been-working-here-ten-years) 及 British Council 的 [future perfect](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/future-continuous-future-perfect)。补充例句和练习为自行编写。
- 三阶段为学习建议：基础6种、进阶4种、拓展6种；不把它表述为某年级教材必须恰好覆盖的范围。

更新核心教材后运行：

```sh
python3 scripts/build-grammar-content.py
```

生成脚本核对题量、唯一编号、答案缺失、空数及配套答案；源文件的 SHA256 写入生成文件。`doc/` 本身被仓库忽略，生成后的 JSON 已随功能代码保存，运行不依赖本地教材文件。

## 学习与交互

- 界面和学习提示使用初高中生能直接理解的说法，如“英语时态”“句型结构”“查看结果”。导入教材原文、题目和答案保留，学习提示单独改写。
- 四个语法页面通过 `useGrammarTheme` 同步原生导航栏与当前主题背景；不改变其他页面的导航栏样式。
- 场景切换、肯定/否定/疑问句切换、完整用法与易混点、16种时态全景。
- 顶部卡片并列显示学习、练习、错题复习三个按钮，错题按钮保留全部错题入口；时态列表仅显示名称和进度，整卡点击进入讲解，返回目录后顶部同步为点击的时态。没有单独的错题入口行或列表操作按钮。
- 该时态全部练习答对、错题清零后自动显示“已学完”。练习未完成时不显示状态标签，不设手动标记学完；旧已读记录保留兼容，但不再影响状态判断。
- 教材练习、专项练习、拓展练习及三类综合练习各自保存会话。点击练习直接续练该组；时态入口续练最近使用的未完成练习组。没有5题分组或题量选择。
- 已练为至少提交过一次的题数；剩余为未完成题数，包含未练题和未改正的错题。答对才计为完成，提示后答对和开放题自评答对同样计为完成，仍不计入独立答对。
- 选择及填空自动核对，支持多空独立输入、大小写、常见缩写、教材列出的多个答案。
- 翻译、订正、改写、写作对照范例后自评，其他正确表达可以接受。自评、提示后答对、独立答对分别显示；自评不计入独立答对。
- 每次输入、提示、提交与翻页保存；原生返回、重新进入或重启后可继续。提交后保留解析，学生点“下一题”才推进。
- 答错立即加入错题，各时态、各练习组和全部错题均有独立入口。复习答对立即移出错题并计为完成；复习仍错则保留。复习会话和常规练习草稿分开保存。
- 重做图标放在时态卡片和练习组右上角，提交过题目后才显示；未提交答案或只保存草稿时不显示，卡片底部不再预留重做行。
- 全部答对后显示“练习已全部完成，做得很好！”，仍可重新练习；重新开始前确认，仅清空相应练习的进度和错题，完成标记随进度自动取消，其他组进度保留。
- 结果页开始下一轮使用 `redirectTo`，避免多轮练习累积页面层级。
- 记录键为 `gotit:grammar:v2`，完全独立于词汇掌握数据；首次打开迁移原 `gotit:grammar:v1` 的学习、答题记录和当前草稿，保留旧存储。记录保存在当前设备，尚无跨设备同步。旧版本未保存每题最后正误，只能用独立答对、复习列表及最后会话推断完成状态。
- 无法写入本机时保留当前会话，并显示保存失败提示。

## 验证与边界

初版验证了教材覆盖、答案核对、提示/自评分开计数、重复提交和草稿恢复；新版增加多时态/练习组独立草稿、即时错题复习、重新开始范围、旧记录迁移和506题全部完成检查。初版微信开发者工具检查了语法 → 讲解 → 填答 → 解析 → 原生返回 → 续练草稿恢复。H5 检查320/375/390/430宽、全景16格、拓展6种、多空题、开放题自评、语篇上下文和结果页。入口迁到首页后，增加了从练习返回目录、直接打开练习后进入目录、已在目录时不重复跳转的导航检查。

微信与 H5 构建通过。真机软键盘高度、系统右滑返回及不同设备安全区仍需真机验收；开发者工具和浏览器不能替代真机证据。全项目 typecheck 有开发前已存在的6处测试文件错误，语法模块没有新增类型错误。
