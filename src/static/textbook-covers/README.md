# 教材封面缩略图

此目录存放当前小程序教材清单实际使用的 JPG 封面，文件名格式：

`{出版社ID}-{册ID}.jpg`

例如译林版七年级上册：

`ylj-grade-7-1.jpg`

图片未上传或加载失败时，首页会自动显示文字版教材封面。

封面统一为 256 × 336、JPEG 88 品质，已按首页 64 × 84 的展示比例补边，
不会拉伸或裁掉教材封面。使用以下命令从国家中小学智慧教育平台同步：

`pnpm covers:sync`
